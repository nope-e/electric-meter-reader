## ONNX 对照与产物

对本批实际保存的 85 个模型输入，分别用原始 TFLite/LiteRT 和 ONNX Runtime CPU 单线程推理：两个模型均为 **85/85 原始输出逐值相同，最大绝对误差 0**。附加的 434 个合成输入也均一致。由此，这批复现的错误在原生模型中同样存在，不能归因于 ONNX 转换。

模型、阈值、推理记录与逐图说明：

- `results/test_wheel_area/`：`detections.json`、两页 `overview_unlabeled_*.jpg` 原图定位、两页 `areas_unlabeled_*.jpg` 读数区裁剪。
- `results/test_wheel_onnx/`：`readings.json`、`readings.csv`、两页 `overview_*.jpg` 切位框、两页 `slots_*.jpg` 实际输入预览、`slots/` 与 `inputs/`。
- `results/test_wheel_onnx/evaluation.json`：23 张逐图目视记录、阶段统计、模型哈希和测试边界。
- `results/test_wheel_onnx/export_verification.json`：本批 85 个输入及合成输入的原生/ONNX 完整核验与输入哈希。

复现（换新输出目录，避免覆盖）：

```powershell

```

当前整链路未达到稳定读数：后续应分别改进漏检、轮位定位，以及识别输入适配/整数附近的解码验证。若用这批图调规则，应另留新图验证，继续保留本次冻结基线。
